Single-file page to eyeball how a theme renders native form controls, autofill, selection, scrollbars and validation states in light and dark mode. The form below uses real autocomplete tokens so the browser's autofill dropdown will offer suggestions once you have saved addresses / cards / logins.

1b. Autofill on a forced-dark form

This section is locally forced to a dark color-scheme with a dark input background (mimicking pure-min.css's .pure-form input[type="text"]), regardless of the page toggle above. It reproduces the case where a light theme's autofill popup renders light text on its light background because Firefox computes the content popup in the page's dark scheme. Fields reuse the same autocomplete tokens, so once you've submitted section 1 the dropdown offers the same suggestions here -- they should stay readable.

The Group tag field below is backed by a <datalist>. It drives the same #PopupAutoComplete panel as form autofill, but its options are declared in HTML, so it reproduces the popup deterministically with no saved history -- focus it and press Down (or type "a") to open it.
